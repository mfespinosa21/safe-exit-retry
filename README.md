# Safe Exit Retry

Safe Exit Retry is a fictional training prototype for one bounded emergency-rehearsal loop.

It reports **performance in simulation only**. It is not a real emergency system and does not measure or predict readiness, compliance, competence, safety, survival, certification, or risk reduction.

The prototype uses a static browser simulation, transparent adaptive logic, and browser voice input with a typed fallback. It stores no personal information, audio, transcript, or result.

Open `dist/index.html` to run it locally.
